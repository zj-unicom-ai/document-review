# 使用指南

本指南面向平台超管、租户管理员和规则配置人员，介绍从登录到下载批注 PDF 的
完整流程。

## 1. 登录

访问 Web 地址，例如：

```text
http://localhost:8080
```

首次部署默认账号：

```text
租户：superadmin
账号：admin
密码：Changeme@2026
```

登录后请立即修改默认密码。

## 2. 选择租户

平台超管登录后可以在左侧品牌区选择租户：

1. 点击“切换”；
2. 选择目标租户；
3. 页面会按新租户重新加载数据。

普通租户用户固定访问所属租户，不需要也不能切换到其他租户。

## 3. 创建业务租户

平台超管进入“租户管理”：

1. 点击新增租户；
2. 填写租户编码、名称和备注；
3. 创建后为该租户创建首个管理员。

租户编码用于 API 请求和存储隔离，创建后应保持稳定。

## 4. 创建租户用户与角色

租户管理员进入“用户管理”和“角色管理”：

1. 创建用户并设置初始密码；
2. 为用户绑定角色；
3. 通过角色控制可见菜单；
4. 提醒用户首次登录后修改密码。

内置管理员角色权限固定，普通角色可以按需要调整菜单授权。

## 5. 定义概念

概念是规则的检查对象。进入“概念管理”，创建：

| 字段 | 建议 |
| --- | --- |
| 概念编码 | 稳定英文或拼音编码 |
| 概念名称 | 面向业务人员的名称 |
| 别名 | 文档中可能出现的同义写法 |
| 数据形态 | 章节、表格、字段、图片组或条目列表 |
| 说明 | 描述该概念对应文档中的哪类内容 |

概念越清楚，画像绑定和规则执行越稳定。

## 6. 定义分类

分类用于组织规则和审查结果。可以维护两级分类，规则可以挂载到最末级分类。
审查详情会按分类汇总违规，便于业务人员阅读。

## 7. 创建规则

进入“规则管理”，按表单创建规则：

1. 填写规则编码和名称；
2. 选择检查对象概念；
3. 选择检查目标；
4. 选择检查能力；
5. 填写能力参数；
6. 配置违规标题和内容模板；
7. 保存规则。

平台提供规则试跑 API，可用于调试未保存或编辑中的规则；它不会生成正式审查
记录。页面中的样例试跑入口位于“模板管理”，用于查看画像绑定与规则命中预览。

## 8. 创建规则集

进入“规则集管理”：

1. 点击新增规则集；
2. 选择一个或多个启用规则；
3. 调整执行顺序；
4. 如需要，配置参数覆盖；
5. 保存规则集。

上传 PDF 时必须选择规则集。

## 9. 管理模板

模板用于保存文档结构画像和概念绑定。进入“模板管理”：

1. 上传代表性 PDF；
2. 查看画像与规则命中预览；
3. 确认绑定正确后固化模板；
4. 将模板绑定到规则集。

如果文档结构变化，可以先试跑并确认后再更新模板。

## 10. 上传 PDF 并开始审查

进入“文档审查”：

1. 选择租户；
2. 选择规则集；
3. 点击上传 PDF；
4. 选择本地文件；
5. 点击开始审查。

页面会显示审查状态。等待状态变为已完成或失败。

## 11. 查看审查结果

打开审查详情，可以查看：

- 整体结果；
- 违规数量；
- 执行规则数；
- 违规分类；
- 每条违规的页码与说明；
- 规则执行状态；
- 失败或跳过原因。

## 12. 查看 trace

对理解类规则，可以查看执行 trace，包括：

- 使用模型与档位；
- 请求上下文摘要；
- 结构化响应；
- 工具调用；
- 耗时；
- 错误信息。

## 13. 下载批注 PDF

审查详情页点击“下载批注 PDF”。批注 PDF 包含：

- 违规位置标注；
- 侧边栏违规说明；
- 页码与规则信息。

## 14. 常见状态

| 状态 | 含义 |
| --- | --- |
| `pending` | 已创建，等待执行 |
| `parsing` | 正在解析 PDF |
| `profiling` | 正在构建文档画像 |
| `planning` | 正在加载规则计划 |
| `executing` | 正在执行规则 |
| `aggregating` | 正在汇总结果 |
| `completed` | 审查完成 |
| `failed` | 审查失败 |
